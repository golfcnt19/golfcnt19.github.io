**เว็บจริง:** https://golfcnt19.github.io

## แก้เนื้อหายังไง

เนื้อหาทุกตัวอักษรอยู่ใน **[`js/content.js`](js/content.js)** ไฟล์เดียว
ไม่ต้องแตะ `index.html` หรือ `css/site.css` เลย

เปิดไฟล์ขึ้นมา จะเห็นโครงแบบนี้

```js
const CONTENT = {
  meta: { ... },   // ชื่อ อีเมล ลิงก์ — ใช้ร่วมกันทั้งสองภาษา
  th:   { ... },   // ข้อความภาษาไทยทั้งหมด
  en:   { ... },   // ข้อความภาษาอังกฤษทั้งหมด
};
```

ทุกจุดที่เขียนว่า `TODO` คือที่ที่ควรใส่ข้อมูลจริงของคุณ

### กฎ 3 ข้อที่ต้องระวัง

1. **`th` กับ `en` ต้องมีคีย์เหมือนกัน** และ array ต้องยาวเท่ากัน
   ถ้าเพิ่มโปรเจคในฝั่ง `th` ต้องเพิ่มในฝั่ง `en` ด้วย ไม่งั้นสลับภาษาแล้วจะหาย
2. **ข้อความอยู่ในเครื่องหมายคำพูด** ถ้าจะพิมพ์ `"` ข้างในข้อความ ให้เขียน `\"`
3. **ลบรายการต้องลบทั้งบล็อก** ตั้งแต่ `{` ถึง `},` รวมลูกน้ำท้ายด้วย

### ตัวอย่าง เพิ่มโปรเจคใหม่

ในทั้ง `th.projects.items` และ `en.projects.items` เพิ่มบล็อกนี้

```js
{
  name: "ชื่อโปรเจค",
  kind: "Web App",              // ป้ายเล็กมุมบนซ้ายของการ์ด
  desc: "อธิบายสั้น ๆ ว่าทำอะไร แก้ปัญหาอะไร",
  tags: ["Flutter", "Firebase"],
  repo: "https://github.com/golfcnt19/ชื่อ-repo",
  live: "",                      // ใส่ URL เว็บจริง หรือเว้นว่างไว้
  highlight: false,              // true = การ์ดเด่น มีป้าย FEATURED
},
```

### ถ้ายังไม่มีประสบการณ์ทำงาน

ลบรายการใน `experience.items` ให้เหลือ `items: []` ทั้งสองภาษา
section นั้นจะว่างแทนที่จะโชว์ TODO

## ดูผลก่อน push

```bash
npx --yes serve . -l 4173
```

แล้วเปิด http://localhost:4173

ดับเบิลคลิก `index.html` เปิดตรง ๆ ก็พอดูได้ แต่แนะนำให้ใช้เซิร์ฟเวอร์
เพราะบางเบราว์เซอร์จำกัดการทำงานของหน้าเว็บที่เปิดจาก `file://`
เช่นการจำภาษาที่เลือกไว้อาจไม่ทำงาน และผลที่เห็นจะไม่ตรงกับตอนขึ้นจริงบน GitHub Pages

## Deploy

**ตั้งค่าเรียบร้อยแล้ว** — GitHub Pages เสิร์ฟ branch `main` จาก root
แก้ไฟล์แล้ว push ขึ้น `main` เว็บจะอัปเดตเองใน 1–2 นาที

```bash
git add -A; git commit -m "update content"; git push
```

### ค่าที่ตั้งไว้

| | |
|---|---|
| repo | `golfcnt19.github.io` — ชื่อต้องเป็น `<username>.github.io` เป๊ะ ๆ GitHub ถึงเสิร์ฟที่ root |
| visibility | public (GitHub Pages ฟรีใช้กับ private ไม่ได้) |
| Pages source | Deploy from a branch · `main` · `/ (root)` |

ถ้าเปลี่ยนชื่อ repo เมื่อไร URL จะกลายเป็น `golfcnt19.github.io/<ชื่อ-repo>/` แทน root
ซึ่งจะทำให้ `canonical` กับ `og:url` ใน `index.html` ผิด ต้องตามแก้ด้วย

ไฟล์ `.nojekyll` ที่อยู่ใน repo มีไว้กัน GitHub Pages ประมวลผลแบบ Jekyll
ซึ่งจะทำให้โฟลเดอร์ที่ขึ้นต้นด้วย `_` หายไป — อย่าลบไฟล์นี้

## โครงสร้างไฟล์

| ไฟล์ | หน้าที่ | ต้องแก้ไหม |
|---|---|---|
| `js/content.js` | เนื้อหาทั้งหมด ไทย+อังกฤษ | **ใช่ แก้ที่นี่** |
| `index.html` | โครงหน้าเว็บ 9 section | นาน ๆ ครั้ง |
| `css/site.css` | สีและหน้าตาทั้งหมด | ถ้าอยากเปลี่ยนสี ดูบล็อก `:root` บนสุด |
| `js/site.js` | สลับภาษา, scroll, นับเลข | ไม่ต้อง |
| `.nojekyll` | ไฟล์ว่างที่ต้องมี | ห้ามลบ |

### เปลี่ยนสีธีม

แก้ที่บล็อก `:root` บนสุดของ `css/site.css` — สองบรรทัดนี้คุมโทนทั้งเว็บ

```css
--acc:  #4fd1c5;   /* สีเน้นหลัก (มิ้นต์) */
--acc2: #f0a868;   /* สีเน้นรอง (ส้ม) */
```

## สิ่งที่ทำไว้ให้แล้ว

- สลับ ไทย/EN จำค่าที่เลือกไว้ ครั้งหน้าเปิดมาได้ภาษาเดิม
- responsive ตั้งแต่จอ 360px มีเมนูแฮมเบอร์เกอร์บนมือถือ
- เคารพ `prefers-reduced-motion` — ปิดอนิเมชันให้คนที่ตั้งค่าไว้
- เนื้อหา **มองเห็นได้เสมอ** แม้ JavaScript พังหรืออนิเมชันไม่ทำงาน
- ปุ่มคัดลอกอีเมล มี fallback สำหรับเบราว์เซอร์เก่า
- meta tag สำหรับแชร์ลิงก์ (Open Graph) และ favicon ฝังในไฟล์ ไม่ต้องมีรูปแยก

## ข้อควรรู้

- `content.js` เป็นไฟล์สาธารณะ ใครก็เปิดดูได้ — **อย่าใส่เบอร์โทรหรือที่อยู่บ้าน**
  ถ้าไม่อยากให้คนทั่วไปเห็น
- อีเมลที่แสดงบนหน้าเว็บมีโอกาสโดนบอทเก็บไปส่งสแปม เป็นเรื่องปกติของการใส่อีเมลบนเว็บ
- ฟอนต์โหลดจาก Google Fonts ถ้าโหลดไม่ได้จะใช้ฟอนต์ของเครื่องแทน หน้าเว็บยังใช้งานได้
